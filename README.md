# 👥 HR Analytics Dashboard

##  Project Overview

**HR Analytics – Employee Attrition Analysis** is an Excel-based data analysis project focused on understanding employee information, workforce characteristics, job satisfaction, and employee attrition.

The project analyzes employee-level HR data to identify patterns related to **attrition, departments, job roles, salary, job satisfaction, work experience, overtime, work-life balance, and employee demographics**.

The analysis is performed using **Microsoft Excel**, with calculations and Pivot Table-based analysis used to generate meaningful HR insights.

---

##  Project Objectives

The main objectives of this project are:

* Analyze employee attrition patterns.
* Understand employee demographics.
* Analyze employee distribution across departments.
* Examine job roles and job levels.
* Analyze employee job satisfaction.
* Study the impact of overtime on attrition.
* Analyze salary and income-related information.
* Examine employee work experience.
* Analyze years employees have spent with the company.
* Understand work-life balance and employee satisfaction.
* Identify patterns that may be associated with employee attrition.
* Present HR insights through an Excel dashboard.
